# KeJiShuCloud 3.0 — Roadmap and release record

## Delivered in 3.0 candidate

- Completely replaced Academic Pages/Jekyll runtime with Astro, TypeScript and component-based static architecture.
- Cobalt/violet design tokens, large responsive editorial type, cinematic Hero, authentic public GitHub projects.
- Insights, four topic routes, AI tools directory/details/comparison, Lab, Projects, About, Search, Privacy, Atom.
- Four localized navigation systems, 8 source-backed article translations, canonical/hreflang, XML sitemap.
- Reduced-motion, no-JavaScript content and menu, GPU-conditional Shader with non-GPU fallback.
- Safe modular Python audit and draft management with tests.
- GitHub Actions static build, typed content validation, SEO/link audit, browser/viewport QA and Pages artifact.
